  # Lab Task 8 – Web Design and Development (WDD)

  This folder contains **Lab 8**, a JavaScript-driven blog listing demo that fetches post data from a public API and dynamically renders responsive Bootstrap cards with randomized styling.

  ---

  ## 📝 Task Overview

  The lab demonstrates how to fetch JSON data from an external endpoint, process it in JavaScript, and generate DOM elements to display content. The UI uses Bootstrap for layout and Font Awesome for icons. Each post is rendered as a card with randomly generated colors for borders, titles, tag badges, and reaction icons to illustrate dynamic styling and DOM manipulation.

  ### Key Concepts Covered:

  - Fetching remote data with the Fetch API and async/await
  - Error handling for network requests
  - Creating and inserting DOM elements dynamically
  - Using Bootstrap grid classes for responsive card layout
  - Applying inline styles and randomization for visual variation
  - Basic use of Font Awesome icons for UI affordances

  ## ✅ Task Requirements

  - Fetch and display a collection of posts from a public JSON endpoint
  - Render posts responsively using Bootstrap grid classes
  - Demonstrate dynamic DOM generation and inline styling from JavaScript
  - Handle fetch errors and fallback gracefully (empty state / console errors)

  ## ✨ Outcome

  This lab results in a responsive, dynamic blog listing that combines network requests, DOM manipulation, and Bootstrap layout to create reusable UI cards. The demo is a practical example of how front-end apps fetch and render data without a framework.
